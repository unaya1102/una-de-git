# 2026-08-07 今天学的单词 · 형용사 (DV: Descriptive Verbs / 形容词)

来源：한국어문화교육원 1급 讲义两页，共 **40 词**，绝大多数成**反义对**出现。

> ⚠️ 和本仓库的「汉字词外挂」不同：形容词几乎全是**固有词**，推不出汉字音，只能靠成对记 + 图像记。
> 全表里只有 **친절하다 = 親切하다** 能用汉字外挂（친=亲，절=切）。

## 三、三条规则，比背单词更省事

### 1. 합니다체：看词干最后一个字有没有收音
- 有收音 → **-습니다**：많다 → 많**습니다**、좁다 → 좁**습니다**
- 无收音 → **-ㅂ니다**：크다 → 큽니다、예쁘다 → 예쁩니다、비싸다 → 비쌉니다
- 收音是 **ㄹ** → 掉 ㄹ 再加 -ㅂ니다：길다 → ~~길습니다~~ → **깁니다** ★

### 2. ㅂ 불규칙（本课重灾区，14 个）
词干收音 ㅂ + 元音词尾 → **ㅂ 变 우**：
`덥다 · 춥다 · 쉽다 · 어렵다 · 두껍다 · 뜨겁다 · 차갑다 · 무겁다 · 가볍다 · 시끄럽다 · 어둡다 · 무섭다 · 귀엽다 · 더럽다`

    덥 + 어요 → 더우 + 어요 → 더워요       덥 + 은 → 더운

**例外（规则变化，别套错）**：좁다 → 좁아요，넓다 → 넓어요，짧다 → 짧아요。
> 记法：**「窄、宽、短」三个跟形状有关的是老实的，跟感觉有关的全是不规则。**

### 3. 으 탈락 / 르 불규칙
- 으 탈락：크다 → **커요**，예쁘다 → **예뻐요**，아프다 → **아파요**（看前一个音节元音定 아/어）
- 르 불규칙：빠르다 → **빨라요**（르 前加 ㄹ）

## 四、最容易混的几组

| 容易混 | 区别 |
|---|---|
| 덥다 / 뜨겁다 | 덥다＝**天气**热；뜨겁다＝**东西**烫（커피가 뜨거워요）|
| 춥다 / 차갑다 | 춥다＝**天气**冷；차갑다＝**东西**凉（물이 차가워요）|
| 적다 / 작다 | 적다＝数量**少**；작다＝体积**小** |
| 얇다 / 짧다 | 얇다＝**薄**（厚度）；짧다＝**短**（长度）|
| 싸다 / 비싸다 | 싸다＝便宜；비싸다＝贵（多一个 비，反而是"贵"）|

## 五、自测（遮住右栏）

1. 이 책은 ( ) → 这本书很厚。 … **두껍습니다 / 두꺼워요**
2. 오늘 날씨가 ( ) → 今天天气冷。 … **춥습니다 / 추워요**
3. 머리가 ( ) → 头发长。 … **깁니다 / 길어요** ★
4. 시험이 ( ) → 考试难。 … **어렵습니다 / 어려워요**
5. 방이 ( ) → 房间干净。 … **깨끗합니다 / 깨끗해요**
6. 선생님이 ( ) → 老师很亲切。 … **친절합니다 / 친절해요**
7. 강아지가 ( ) → 小狗可爱。 … **귀엽습니다 / 귀여워요**
8. 지하철이 ( ) → 地铁快。 … **빠릅니다 / 빨라요**
