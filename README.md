# 한자어 외괘 · 汉字词外挂

面向**中文母语者**的韩语速成工具：利用「汉字 ↔ 固定韩音」对应关系，把约 57% 的韩语汉字词（한자어）变成可批量推导的再认词汇。配套**间隔重复（SRS）**自动排程，落地杨鹏《17天》式「低门槛第一遍 + 严格复习 + 记不住的拎回来重背」方法。

> 目标定位：**再认（看懂就行）**，不追求拼写/产出。

## 两种用法

### A. 手机/离线直接用（推荐出差用）
打开 **`standalone.html`** 单文件即可——所有代码内联，**双击就开、断网照常用**。
- 手机：把文件存到「文件」App，用浏览器打开；或加到主屏。
- 数据存在浏览器本地，换设备不同步。

### B. GitHub Pages 网址（多设备、可安装为 App）
仓库已含 `index.html` + `sw.js` + `manifest.json`（PWA，可离线、可加到主屏）。
启用方法：仓库 **Settings → Pages → Source 选本分支 → 根目录**，几分钟后用给出的网址打开即可。

## 课堂词卡（固有词，另一套）
`adjectives.html` — 2026-08-07 课上的 40 个形容词（한국어문화교육원 1급）。单文件，双击就开、断网可用。
三种方向（한→中 / 中→한 / 활용），可按 **ㅂ 불규칙 / ㅡ·르·ㄹ / 하다·있다 / 易混词 / 页码** 筛选；
点「몰라요」的词自动排到本轮末尾重来，并进入「약한 카드」。文字版见 `notes/2026-08-07-형용사.md`。

> 形容词是固有词，推不出汉字音，所以不进 `data.js`——那边只放한자어。

## 功能
- **학습（学习）**：两种练法
  - `汉字 → 推读音/意思`：练你的母语外挂（核心）
  - `한글 → 推意思`：练实战再认
- **한자음표**：高频「汉字→韩音」对照，背熟即可批量推词。
- **통계**：进度、待复习数、每天新词上限可调。
- **SRS 周期**：10分 → 1 → 2 → 4 → 7 → 15 → 30 → 60 天；点「몰라요」即把词拎回当轮重背。

## 调整词库
编辑 `data.js`（多文件版）中的 `window.WORDS`，按现有格式增删。
单文件版改完 `data.js` 后重新生成 `standalone.html`（见 git 历史里的内联命令）。

## 重要提醒
汉字词偏书面/正式，日常口语有时用固有词。该工具让「阅读再认」飞快，但不等于会说——与「看懂就行」的目标一致。
